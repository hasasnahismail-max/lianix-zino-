# LIANIX ZINO - Tactical E2EE Messaging System

LIANIX ZINO is a tactical, end-to-end encrypted (E2EE) messaging platform built with Node.js, Socket.io, and React. Designed for secure, real-time communications over isolated networks.

## 🚀 Architecture Overview

- **Server (`/server`)**: Node.js & Express relay node utilizing Socket.io for encrypted realtime message routing.
- **Client (`/client`)**: React tactical dashboard interface.

## 🛠️ Getting Started

### 1. Run Server
```bash
cd server
npm install
npm start
```

### 2. Run Client
```bash
cd client
npm install
npm start
```

## 🔒 Security & Privacy
- Zero-knowledge message relay node architecture.
- Designed for tactical privacy and localized channel encryption.
